# 技术文档索引（测试数据）

本目录收录本项目开发过程中的**部分真机实测报告**。全部内容基于真机数据，
包括若干"不好看"的结论 —— 它们同样是本项目的价值所在。

> 🔒 **隐私说明**：本目录所有文档在发布前已做脱敏处理。设备 IP 地址、
> 登录账号口令、本机目录路径、个人主页链接等敏感信息均已替换为占位符
> （如 `<LAN_IP>`、`<REDACTED>`）或移除。
>
> ⚠️ **阅读提醒**：这些报告按时间顺序记录了认识不断被修正的过程。
> 其中**存在已被后续实测推翻的早期结论**。
> 当报告之间冲突时，**以时间最新者、以及源码注释为准**。
> 典型例子：
> - 曾判定"CMA 被安卓容器占满 1.1GB" → 实为内核 movable 页借用，
>   硬件 dma-buf 实测仅 35.5 MB（见 `CMA占用归因排查报告.md`）
> - 曾认为"并发两个解码会话无害" → 实测触发固件死锁导致断电
> - 曾以为硬解必然省 CPU → 真实播放器实测为**负收益**
>   （见 `硬解优化与软硬解切换_2026-10-04.md`）
